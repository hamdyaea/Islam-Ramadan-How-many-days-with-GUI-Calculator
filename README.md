# Ramadan Date Estimate Calculator

**Developer:** Hamdy Abou El Anein  
**Contact:** info@daylightlinux.ch  
**License:** GPL v3 (see LICENSE).

A modern Python 3/Tkinter calculator for the number of days to a selected historical estimated Ramadan start. The original project's estimated dates are retained and made explicit, including the two estimated Ramadan starts in Gregorian year 2030. The program does not calculate the lunar calendar or automatically fetch official dates.

```sh
python3 ramadanCalculator.py
python3 ramadanCalculator.py --year 2026
python3 -m unittest discover -s tests -v
```

**Important:** These historical estimates are not independently verified and may differ from the official date established by local religious authorities or moon sighting. Do not use this tool as the authoritative date for religious observance.

Original EasyGUI version: [old branch](https://github.com/hamdyaea/Islam-Ramadan-How-many-days-with-GUI-Calculator/tree/old).
